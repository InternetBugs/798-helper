# 798 助手

让「慧生活798」安静下来的 LSPosed 模块。

开屏广告、横幅、信息流、激励视频、插屏、商城广告全部不再加载；底部「积分」选项卡和「我的」页的积分入口一并移除。

只对「慧生活798」生效，不影响系统和其他应用。

**[⬇ 下载最新版](../../releases/latest)** · [安装](#安装) · [常见问题](#常见问题)

---

## 装完之后

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| 启动 App | 开屏广告，等几秒 | 直接进首页 |
| 首页 | 横幅广告、信息流广告 | 干净 |
| 积分任务 | 「看广告赚积分」入口 | 干净 |
| 各处弹窗 | 插屏、全屏广告 | 不再出现 |
| 商城页 | 商城广告 | 干净 |
| 底部导航 | 首页 / **积分** / 服务 / 我的 | 首页 / 服务 / 我的 |
| 「我的」页 | 钱包 / 卡包 / 卡券 / **积分** | 钱包 / 卡包 / 卡券 |

广告位是被"掐断"的——模块直接拦掉广告请求，界面走「广告加载失败」的正常分支，所以不会出现空白框或者转圈卡住。

## 前提条件

- 手机已 root（KernelSU、Magisk 都行）
- 已安装 [LSPosed](https://github.com/LSPosed/LSPosed)
- 「慧生活798」版本 **3.1.10**。其他版本没测过，可能部分失效

## 安装

1. 到 [Releases](../../releases/latest) 下载 `798-helper.apk`
2. 安装它。**桌面和应用列表里不会出现图标，这是正常的**——它没有界面，是个后台模块
3. 打开 **LSPosed** → 底部「模块」→ 找到「**798 助手**」→ 打开右边开关
4. 点进「798 助手」，在作用域里勾选「**慧生活798**」
5. 强制停止「慧生活798」（设置 → 应用 → 慧生活798 → 强行停止），然后重新打开

第 5 步别省。模块只在目标应用启动时加载，不强制停止一次不会生效。

## 常见问题

**LSPosed 的模块列表里找不到它**

先把列表下拉刷新一次。还是没有的话，确认装的是 Releases 里的那个 apk，然后在终端跑 `adb shell pm list packages | grep internetbugs`，能查到 `io.github.internetbugs.helper798` 就说明装上了。

**装好了、开关也开了，广告还在**

九成是作用域没勾。LSPosed → 模块 → 798 助手，确认「慧生活798」那一项打勾，然后强制停止目标应用再打开。改完作用域不需要重启手机，但必须强制停止一次。

**更新模块要重新设置吗**

不用。直接装新版覆盖安装，LSPosed 里的开关和作用域都会保留。

**从 1.3.x 升上来要注意什么**

1.4.0 起模块包名是 `io.github.internetbugs.helper798`（1.3.x 是 `com.n798.cloudora`）。装好新版后确认 LSPosed 里「798 助手」开关已打开、作用域勾选了「慧生活798」，再强制停止「慧生活798」重新打开。

**想临时关掉**

LSPosed 里关掉「798 助手」的开关，强制停止「慧生活798」，重新打开。因为模块没有桌面图标，只能从 LSPosed 管理器里找到它。

**卸载**

先在 LSPosed 里关掉开关，再正常卸载 apk。

**会不会影响别的应用**

不会。作用域只有「慧生活798」一个包，模块代码只在这个进程里加载。

**安全吗，会不会封号**

模块只拦截广告请求，不改登录状态、不改数据、不联网、不上报任何东西。但任何修改客户端的行为都有风险，自己权衡。

**支持其他版本吗**

只针对 3.1.10 验证过。应用更新后如果广告又出现了，说明广告入口的类名变了，需要重新适配。
